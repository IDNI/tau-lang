NOTICES for software of other projects used by the Tau Language Framework
=========================================================================

The Tau Language Framework is developed by IDNI AG and is licensed under the
terms of LICENSE.md. It uses the software listed below, each part under its own
license. Every package carries the license texts in a `licenses` folder:
`share/doc/tau/licenses` in the Linux and Windows packages, `licenses` beside
`tau` in the macOS package, `licenses` in the SDK, `tau/licenses` in the Python
wheel and `licenses` in the JavaScript package.


Linked into Tau
---------------

Tau Parsing Library (IDNI AG)
  Tau uses it internally. The license of the Tau Language Framework does not
  grant a license to the Tau Parsing Library; using it directly requires a
  separate license. License: licenses/parser-sdk/LICENSE.md.

Boost 1.86 (Boost Software License 1.0)
  Logging, threads and file system support. Linked statically.
  https://www.boost.org/

FTXUI (MIT License)
  The interactive prompt of the `tau` executable. Linked statically.
  https://github.com/ArthurSonzogni/FTXUI

unordered_dense (MIT License)
  Hash maps and sets. Header-only.
  https://github.com/martinus/unordered_dense

nanobind and robin_map (BSD 3-Clause License, MIT License)
  The Python binding only. Linked statically into the Python module.
  https://github.com/wjakob/nanobind

curl 8.11.1 (curl license, MIT-style)
  The HTTP requests of the natural-language algebra. Linux and macOS use the
  curl of the system. The Windows packages link curl statically, built with the
  Windows TLS support and no other dependency. https://curl.se/

cvc5 1.3.1 (BSD 3-Clause License)
  The solver behind the bitvector and half-space algebras. Shipped as a separate
  shared library. It is built from source with `--no-gpl` and `--no-poly`, so
  it links none of the optional GPL or LGPL components of cvc5 (CLN, GLPK,
  CoCoA, libpoly) and stays under its BSD license. It contains CaDiCaL (MIT
  License), SymFPU (BSD-style license) and parts of MiniSat (MIT License).
  https://github.com/cvc5/cvc5

GMP 6.3.0 (GNU LGPL version 3, or GNU GPL version 2)
  Arbitrary-precision arithmetic, used by cvc5. Shipped as a separate shared
  library, which you may replace with a build of your own. Its source, and the
  scripts that build it, are attached to the GitHub release of every package
  that carries it; licenses/gmp/SOURCE.md says where. https://gmplib.org/


Shipped beside Tau, not linked
------------------------------

Spot 2.16 (GNU GPL version 3)
  The tools ltlsynt, autfilt and ltlfilt, installed under libexec/tau/spot.
  Tau runs them as separate programs and does not link Spot. They contain
  BuDDy, PicoSAT and utfcpp, each under its own permissive license. Their
  source, and the scripts that build them, are attached to the GitHub release
  of every package that carries them; licenses/spot/SOURCE.md says where.
  https://spot.lre.epita.fr/


Runtime libraries
-----------------

GCC runtime libraries (GNU GPL version 3 with the GCC Runtime Library
Exception, version 3.1)
  The C++ runtime of the Linux packages, taken from the system. The Windows
  packages ship the MinGW-w64 libstdc++, libgcc and winpthreads DLLs beside
  the Spot tools, with their licenses.

Microsoft Visual C++ runtime
  The Windows packages ship the redistributable Visual C++ runtime DLLs beside
  tau.exe, under the terms of the Microsoft Visual Studio license.

Emscripten and musl (MIT License)
  The runtime of the WebAssembly build. https://emscripten.org/
