Every notable change to Tau, version by version, written for people who use
the language rather than for people who develop it.

Last generated on 2026-09-22.

### Added

- Specifications can now work with whole numbers of a fixed width, not only with true and false: a value declared as `:bv[32]` supports addition, subtraction, multiplication, division, remainder, shifts, bit operations and comparisons. This is the single largest addition since the alpha, and it is what most of the other new options below exist to serve. (PRs: none / Issues: none / Commits: [909c9917](https://github.com/IDNI/tau-lang/commit/909c991744ead14e1025f019b9d63c156463f005), [d30e847e](https://github.com/IDNI/tau-lang/commit/d30e847e5af4fd5f00bb4a6ce32a29a41beaff61), [c6929e74](https://github.com/IDNI/tau-lang/commit/c6929e74a71868a078b5a112b2b8df8aebc3f3f6), [b50819d3](https://github.com/IDNI/tau-lang/commit/b50819d3c4b0d54f029804e50a0476fdc1079b52), [f5243d88](https://github.com/IDNI/tau-lang/commit/f5243d88ccf5f5d00ed4ba539cab5e292d52480c))
- An optional exact-arithmetic mode for whole numbers. Normally a result too large for its width wraps around silently; with this mode on, intermediate results are computed at whatever width they actually need, so sums and products give the mathematically correct answer. It is off by default because it changes the answer every question about a specification gets; turn it on with the bitvector widening option. (PRs: none / Issues: none / Commits: [5f9b0497](https://github.com/IDNI/tau-lang/commit/5f9b0497053c6ead7e72996b05ecdaf164c8db4a), [083e671d](https://github.com/IDNI/tau-lang/commit/083e671d094fc372af8d2c52a8829d52d5dcf856), [9e9a2317](https://github.com/IDNI/tau-lang/commit/9e9a231702942e067813216b9f9301e966a40341), [a76e603e](https://github.com/IDNI/tau-lang/commit/a76e603e965c485c72c536cce6a29c1e5d47d655), [a11ced8a](https://github.com/IDNI/tau-lang/commit/a11ced8a9d901919bcbcf3644823aa00cfeb51ca), [44a10679](https://github.com/IDNI/tau-lang/commit/44a10679805384be02d164b09c20491e44b3c765))

(PRs: none / Issues: none / Commits: [4437dad2](https://github.com/IDNI/tau-lang/commit/4437dad2cf9b94b228ebb34e68736899020b562d), [02fbae29](https://github.com/IDNI/tau-lang/commit/02fbae296c49b0ded2354d36b989a1bbd6cb4281))
- Tau can now answer questions about whole-number arithmetic by reducing it to plain bit operations, as an alternative to handing the formula to the solver. This makes some specifications solvable that the solver alone could not finish. (PRs: none / Issues: none / Commits: [1908e8fb](https://github.com/IDNI/tau-lang/commit/1908e8fb62fab08c2988478a5d2c5e7844862c1c), [6755cf14](https://github.com/IDNI/tau-lang/commit/6755cf142025370d345bf8ef36285c5dd29a19ad), [2c76cc63](https://github.com/IDNI/tau-lang/commit/2c76cc63d924b4f5749af8243094c1408945bb01), [87338fa6](https://github.com/IDNI/tau-lang/commit/87338fa63cec987946e50c57e488d35f3f1bb9df))
- Specifications can define their own compound types — a named group of fields, which may nest and may inherit — and read and write them as whole values on a stream. Fields are reached by name, and a stream of such values has its own text format on disk and at the prompt. (PRs: none / Issues: none / Commits: [77bc4009](https://github.com/IDNI/tau-lang/commit/77bc4009349f481f0559059a5e3b100c3581faaa), [aebd42be](https://github.com/IDNI/tau-lang/commit/aebd42be05b47cb8b86772d603f77f8855562318), [adb27feb](https://github.com/IDNI/tau-lang/commit/adb27feb5eb4b4c5a93e909643e0738dd5aca78c), [b16b17b1](https://github.com/IDNI/tau-lang/commit/b16b17b16859894c611a29bbfae630d877d3a2a7), [a35d0fed](https://github.com/IDNI/tau-lang/commit/a35d0fed1b79bb80e72f4349419e7d342db17713))
