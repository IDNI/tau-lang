### Added

- Specifications can now work with whole numbers of a fixed width, not only with true and false: a value declared as `:bv[32]` supports addition, subtraction, multiplication, division, remainder, shifts, bit operations and comparisons. This is the single largest addition since the alpha, and it is what most of the other new options below exist to serve. ## [v0.7-alpha](https://github.com/IDNI/tau-lang/releases/tag/v0.7-alpha) (2024-11-16)

The first public release of the Tau Language Framework, published as an alpha.

### Added

- The Tau language itself: a way to write down what a program must do — as Boolean functions, logical formulas and quantifiers — rather than how it should do it.
